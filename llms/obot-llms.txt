# Obot

> Obot AI (formerly Acorn Labs) is an open-source MCP Gateway and platform that gives organizations a central control point for Model Context Protocol (MCP) servers and AI agent Skills — hosting local/remote/multi-tenant MCP servers, an internal MCP catalog, OAuth-based access control, policy enforcement, and audit logging. Written in Go, MIT-licensed, self-hosted on Docker or Kubernetes. This llms.txt was generated by the API Evangelist enrichment pipeline from public sources.

## Product
- [Obot MCP Gateway / Platform](https://obot.ai/): Central control point for MCP servers, Skills, access policies, audit, and integrations for AI agents.
- [Nanobot](https://github.com/obot-platform/nanobot): Standalone open-source MCP host / agent framework CLI for building MCP-powered chatbots and agents.
